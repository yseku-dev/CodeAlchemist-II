# **App Name**: CodeAlchemist

## Core Features:

- AI Code Generation: Generate code snippets based on natural language descriptions, leveraging user-selected AI configurations.
- AI Refactoring: Analyze a project for potential refactoring improvements and show before/after snippets, driven by AI refactoring tool.
- In-App Code Modification: Enable direct code modification within the UI using AI-driven code fixes, providing a streamlined development workflow.
- Self Code Analysis: The application will have the ability to analyze its own codebase. LLM evaluates the state of the code in order to identify bugs or areas to refactor.
- Detailed Error Display: Show descriptive error messages.

## Style Guidelines:

- Use #1A237E as primary color for key actions.
- The application should have light backgrounds for improved visibility.
- Accent: Teal (#26A69A) to call attention to informative icons and CTAs.
- Sans-serif font to ensure legibility and maintain a consistent design across the application
- Consistent icon set to visually represent actions and objects.
- Responsive layout to adapt to mobile and desktop sizes
